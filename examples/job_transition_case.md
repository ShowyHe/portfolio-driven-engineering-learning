# Example: Job Transition Case

## 背景

这个案例说明如何把工程学习成果转化为求职、面试和岗位能力证据。

## 输入材料

学习阶段已经沉淀了：

- GitHub 项目
- README
- runbook
- debug report
- weekly summary
- 实验记录
- 面试问答

## 转化方式

把学习材料整理成面试可表达结构：

1. 项目背景
2. 我的职责
3. 技术路线
4. 遇到的问题
5. 排查过程
6. 解决方案
7. 验证方式
8. 最终结果
9. 个人收获

## 示例表达

我不是只学习了 ROS2 / Nav2 的概念，而是通过真实工程任务完成了环境搭建、导航链路跑通、参数实验、问题排查、文档复盘和面试表达整理。

这些材料最终形成了可以被展示和验证的工程能力证据链。

## 总结

工程作品集驱动学习法的最终目标，不只是学习知识，而是把学习过程转化为职业机会。
