# Example: ROS2 / Nav2 Learning Case

## 项目背景

目标是在两个月内，通过 ROS2 / Nav2 工程实践建立机器人软件工程基础能力，并形成可展示的 GitHub 作品集。

## 起点

最开始的任务不是深入算法，而是先完成基础链路：

- 安装 ROS2 Humble
- 配置 TurtleBot3
- 启动 Gazebo 仿真
- 启动 Nav2
- 在 RViz 中设置初始位姿
- 发送导航目标
- 验证 map、tf、odom、cmd_vel 链路

## 学习方式

采用工程作品集驱动学习法：

1. 先进入真实工程任务
2. 遇到问题后用 AI 辅助拆解
3. 用命令和日志验证结论
4. 阶段结束写文档
5. 通过问答检查理解
6. 最后整理成 GitHub 作品集

## 关键产出

- Nav2 demo 跑通记录
- 参数实验记录
- debug 文档
- runbook
- weekly summary
- 面试问答材料
- GitHub portfolio

## 经验总结

这段学习最重要的收获不是单个知识点，而是形成了完整闭环：

做过 → 记录过 → 复盘过 → 讲得出 → 展示得出
