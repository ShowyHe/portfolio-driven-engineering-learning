# 01 方法总览

## 方法名称

工程作品集驱动学习法  
Portfolio-driven Engineering Learning

## 一句话定义

以真实工程项目为主线，用 AI 辅助推进，用阶段计划控制节奏，用文档沉淀理解，用问答验证掌握，最后整理成 GitHub 作品集和面试 / 申请证据链。

## 核心闭环

真实项目 → AI 辅助 → 限定计划 → 工程调试 → 文档复盘 → 问答验证 → GitHub 展示 → 面试 / 申请转化

## 这个方法解决什么问题

很多自学者的问题不是“不努力”，而是：

- 学习过程没有主线
- 学完没有证据
- 做过项目但讲不清楚
- 调试经验没有沉淀
- 面试时无法证明真实能力

这个方法的目标，是把学习过程变成可以复习、可以展示、可以被验证的工程资产。
