# Portfolio-driven Engineering Learning

## 工程作品集驱动学习法

**Portfolio-driven Engineering Learning** 是我在 AI 时代下，为了更快建立工程能力而总结出的一套学习方法。

它的核心不是“看了多少课程”，而是围绕真实工程项目，把学习、调试、复盘、问答验证和 GitHub 作品集连接起来，最终形成一套可以复习、可以展示、可以面试、可以申请的工程能力证据链。

## 一句话定义

以真实工程项目为主线，用 AI 辅助推进，用阶段计划控制节奏，用文档沉淀理解，用问答验证掌握，最后整理成 GitHub 作品集和面试 / 申请证据链。

## 核心闭环

    真实项目
      ↓
    AI 辅助推进
      ↓
    限定阶段计划
      ↓
    工程调试与验证
      ↓
    文档复盘
      ↓
    问答验证理解
      ↓
    GitHub 作品集整理
      ↓
    面试 / 申请 / 职业转化
