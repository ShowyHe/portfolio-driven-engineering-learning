# 01 方法总览

## 方法名称

工程作品集驱动学习法  
Portfolio-driven Engineering Learning

## 核心定义

工程作品集驱动学习法，是一种面向 AI 时代的工程学习方法。

它以真实工程项目为主线，通过 AI 辅助推进、阶段计划约束、工程调试验证、文档复盘沉淀、问答验证理解，最终形成 GitHub 作品集和面试 / 申请证据链。

## 核心公式

真实项目 + AI 辅助 + 阶段计划 + 工程验证 + 文档复盘 + 问答验证 + GitHub 作品集 = 可验证的工程能力

## 核心闭环

    真实项目
      ↓
    AI 辅助推进
      ↓
    限定阶段计划
      ↓
    工程调试与验证
      ↓
    文档复盘
      ↓
    问答验证理解
      ↓
    GitHub 作品集整理
      ↓
    面试 / 申请 / 职业转化

## 解决的问题

传统自学工程时，常见问题是：

- 学习内容分散
- 学完没有产出
- 做过项目但讲不清楚
- 调试过程没有沉淀
- 面试时缺少证据
- AI 辅助学习容易失控和发散

这套方法的目标，是把学习过程转化为可以复习、可以展示、可以验证的工程资产。

## 方法特点

1. 以真实项目暴露问题
2. 以 AI 提高推进速度
3. 以阶段计划限制发散
4. 以调试记录保留证据
5. 以文档复盘沉淀理解
6. 以问答验证表达能力
7. 以 GitHub 作品集证明能力

## 最终产出

这套方法最终产出的不是单纯笔记，而是：

- 项目代码
- 调试记录
- 实验结果
- README
- runbook
- debug report
- weekly summary
- interview Q&A
- GitHub portfolio

## 一句话总结

工程作品集驱动学习法，本质上是把“学习过程”工程化、文档化、证据化、作品集化。
