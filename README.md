# Portfolio-driven Engineering Learning

## 工程作品集驱动学习法

这是一个面向 AI 时代的工程学习方法。

它的核心不是“看了多少课程”，而是通过真实工程项目、AI 辅助实践、阶段计划、调试记录、复盘文档和 GitHub 作品集，建立一套可复习、可展示、可面试、可申请的工程能力证据链。

## 核心闭环

真实项目 → AI 辅助 → 限定计划 → 工程调试 → 文档复盘 → 问答验证 → GitHub 展示 → 面试 / 申请转化

## 方法来源

这套方法形成于我 2026 年 1 月到 3 月初的两个月集中机器人软件工程学习过程中。

第一周主要完成 ROS2 环境搭建和 Nav2 / TurtleBot3 基础链路跑通；随后围绕 Nav2 工程实践、参数实验、评估脚本、调试文档、阶段总结和面试问答持续迭代。

3 月初后，学习成果进一步转化为求职面试材料和工程能力证据链。

## 适合人群

- 想快速进入工程领域的自学者
- 想用 AI 提升学习效率的人
- 想把学习过程转化为 GitHub 作品集的人
- 想为求职、面试、申请准备项目证据的人
