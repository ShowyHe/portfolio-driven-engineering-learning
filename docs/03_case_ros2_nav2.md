# 03 案例：ROS2 / Nav2 工程学习

## 背景

这个案例记录我在 2026 年 1 月到 3 月初，通过 ROS2 / Nav2 工程实践形成“工程作品集驱动学习法”的过程。

## 时间线

| 时间 | 阶段 | 内容 |
|---|---|---|
| 2026-01-04 到 2026-01-11 | 环境搭建期 | 安装 ROS2，跑通 TurtleBot3 / Nav2 基础链路 |
| 2026-01 中旬到 2026-02 底 | 工程学习期 | Nav2 实验、参数对照、评估脚本、runbook、debug 文档、周总结 |
| 2026-03 初到 2026-03-12 | 求职转化期 | 整理项目表达、准备面试问答、形成工程能力证据链 |

## 方法体现

这段学习不是先系统看完课程再做项目，而是直接进入真实工程问题。

核心流程是：真实项目 → AI 辅助 → 阶段计划 → 工程调试 → 文档复盘 → 问答验证 → GitHub 作品集 → 面试转化

## 核心收获

最终沉淀的不只是 ROS2 / Nav2 知识，而是一套可复用的工程学习闭环：

做过 → 记录过 → 复盘过 → 讲得出 → 展示得出
